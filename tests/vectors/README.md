# RFC 8949 test vectors

`appendix_a.json` contains the Appendix A examples from RFC 7049, obtained from
[cbor/test-vectors](https://github.com/cbor/test-vectors) at commit
`aba89b653e484bc8573c22f3ff35641d79dfd8c1`. The upstream README describes the
file as the RFC 7049 Appendix A examples in JSON form. The upstream repository
has no separate license file.

`appendix_f1.json` contains the malformed encodings from RFC 8949 Appendix F.1.
